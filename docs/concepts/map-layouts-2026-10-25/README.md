# Location layout studies

Seven proposed planning images, generated with built-in image_gen on 2026-10-25. Full prompts are in [prompts.json](prompts.json). Locations follow the seven mission-preview concepts; the game plan currently combines some themes.

These are visual route and landmark studies, not measured implementation plans. Generated grid labels and scale bars are approximate and sometimes inconsistent. Test path widths, connectivity, sight lines, combat space, and extraction distances in a graybox before building art. Some structures are drawn at a slight illustrative angle.

Standard sector target: 160 x 160 m. Hollow target: 90 x 90 m. These targets are provisional, not dimensions verified from the paintings.

Cyan A marks arrival; L1-L3 mark proposed dormant exits; gold diamonds mark optional objectives; dashed white paths suggest alternate routes. In The Hollow, the northern lift is the escape lift despite its generated A icon and generic legend. Stormbringer's storm-basin water needs an explicit walkable-versus-deep-water pass in blockout. Forest axis labels are inconsistent; use the intended 160 m extent, not the printed ticks.
